## 👤 一、用户模块

### 1. 用户登录
- **URL**: `/home/user/login`
- **Method**: POST
- **认证**: 否
- **参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| username | string | 是 | 用户名或手机号 |
| password | string | 是 | 密码 |

- **响应示例**:
```json
{
    "code": 200,
    "msg": "登录成功",
    "data": {
        "user_id": 1,
        "user_id_no": "USER202604190001",
        "user_name": "张三",
        "user_tel": "13800138001",
        "user_token": "token001",
        "user_type": 1,
        "house_id": 1,
        "status": 1
    }
}
```

- **Method**: POST
- **认证**: 否

| username | string | 是 | 用户名 |

```json

    "msg": "注册成功",

        "user_id": 6,
        "user_token": "xxxxxxxxxxxxxxxx"
    }
}
```

## 🔧 常见问题

### 1. HTTP Error: 0
**原因**: 请求超时或服务器未响应
**解决**: 检查网络连接，稍后重试

### 2. HTTP Error: 500
**原因**: 服务器内部错误
**解决**: 检查参数是否正确，联系管理员

### 3. 401 Unauthorized
**原因**: Token无效或已过期
**解决**: 重新登录获取新Token
