## 🔐 认证方式

需要认证的接口在请求头中携带 Token：

```
Authorization: Bearer {token}
```

通过 `/home/user/login` 登录成功后返回 `user_token`。

| 状态码 | 说明 |
|--------|------|
| 200 | 成功 |
| 400 | 参数错误 |
| 401 | 未登录/Token无效 |
| 500 | 服务器内部错误 |
